# Kiragu Johnson — Web Developer Portfolio

A responsive portfolio built as separate Home, About, Services, Projects, and Contact pages with plain HTML, CSS, and JavaScript.

## Run locally

Open `index.html` in a browser. Use the navigation to open each page separately. No build tools or dependencies are required.

## Customize

- Update the About, services, project, and contact copy in their respective HTML pages.
- Replace representative project photos in `assets/` with screenshots of your finished sites when available.
- The CV PDF is stored in `assets/Kiragu_Johnson_Web_Developer_CV.pdf`.
- Update email and phone details on `contact.html`.
- Adjust colors and layout in `styles.css`.

The shared mobile navigation and footer year are handled by `script.js`.
